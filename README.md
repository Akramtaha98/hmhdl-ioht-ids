## What this is

This repository is the full reproducibility package behind a study of IoHT intrusion detection across three benchmarks — **ECU-IoHT**, **WUSTL-EHMS-2020**, and **DSICU**. It includes every script used to preprocess the data, tune and train the hybrid model with the Lionfish Optimization Algorithm, run same-split classical baselines, run an architecture ablation and a random-search control, check robustness under alternative splits and identifier-feature removal, and regenerate every figure and table. All raw result files (JSON) and exact train/test split indices are included, so every number can be traced back to the file that produced it.

## Repository layout

Everything reads and writes relative to the project root (the parent of `code/`), so this can be cloned or unzipped anywhere:

```
supplementary/
├── code/            all Python scripts (see below)
├── data/            place the three raw dataset CSVs here (not redistributed; see Datasets)
├── results/         every raw result JSON file (included)
├── split_indices/   exact row indices, main split + every alternative split (included)
├── figures/         regenerated by code/make_figures.py (not included; run the script)
├── checkpoints/     auto-generated resumable model/optimizer state (not included, regenerated on run)
├── requirements.txt
└── run_all.sh       orchestrates the full pipeline end to end
```

<details>
<summary><strong>📄 <code>code/</code> — what each script does</strong></summary>

<br>

| Script | Purpose |
|---|---|
| `pipeline.py` | Dataset loaders, split-before-fit preprocessing, the CNN-LSTM-GRU-Attention model builder, the Lionfish Optimization Algorithm, and the staged/checkpointed train+evaluate pipeline used to produce the main results. |
| `baselines_and_metrics.py` | Same-split classical ML baselines (logistic regression, random forest, histogram gradient boosting, MLP); probability-based test metrics (ROC-AUC, PR-AUC, per-class precision/recall/F1, specificity, false-negative rate) for the hybrid model and every classical baseline. |
| `search_comparison.py` | Random-search baseline at a budget matched to Lionfish, and the architecture ablation screen (CNN-only, CNN-LSTM, CNN-GRU, CNN-LSTM-GRU, full hybrid, full hybrid with default hyperparameters). |
| `sensitivity_split.py` | v1 of the temporal (ECU-IoHT, WUSTL-EHMS-2020) and flow-grouped (DSICU) alternative-split robustness checks. Kept for transparency; superseded by v2. |
| `no_identifier_check.py` | Re-runs the main (random) split with the capture-order/identifier-like field excluded from the model's input features, isolating its contribution independent of split choice. |
| `sensitivity_split_v2.py` | Revised alternative-split analysis: hyperparameters found by an independently seeded search restricted to each alternative split's own training partition, identifier-like field excluded, budget matched to the main experiment in every respect except the split itself. |
| `repeated_seeds.py` | Trains the final model on the main split with three additional seeds under the identical budget as the original run, and summarizes all runs as mean ± standard deviation. |
| `export_split_indices.py` | Regenerates the exact row indices for the main split and every alternative split (indices are also provided directly in `split_indices/`). |
| `make_figures.py` | Regenerates every figure at 600 DPI from the result JSON files. |
| `references.py` | The manuscript's numbered reference database. |
| `build_manuscript_mdpi_template.py` | Assembles the full manuscript inside the journal's official Word template. Included for transparency, not intended to be re-run by reviewers — it requires a licensed template file not redistributed here. |

## Random seeds

A single fixed seed (**42**) is used throughout the main experiment — NumPy, TensorFlow, and every scikit-learn splitting/estimator call. The random-search comparison uses a distinct stream (42 + 999). The v2 alternative-split hyperparameter search uses yet another distinct stream (42 + 4242). Repeated-seed runs additionally use seeds 43, 44, and 45.

## Environment

Python 3.10. Exact versions in `requirements.txt`: TensorFlow/Keras 2.15.0, scikit-learn 1.7.2, NumPy 1.26.4, pandas 2.3.3, matplotlib 3.10.9, python-docx 1.2.0 (only needed to rebuild the manuscript `.docx`). All experiments were run on **CPU only** — no GPU acceleration required.

```bash
pip install -r requirements.txt
```

## Running everything

```bash
cd supplementary/
# place the three raw CSVs in data/ first — see Datasets above
bash run_all.sh
```

`run_all.sh` runs every stage in the correct order and automatically retries any stage that reports a time-budget checkpoint rather than completion — each stage is independently resumable. See the comments inside `run_all.sh` for expected running time and a stage-by-stage breakdown.
